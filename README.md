# Syntexhub_Dashboard
# E-commerce Admin Dashboard UI

## Project Overview
This project is a web-based admin dashboard UI designed using Figma.
It helps admins monitor sales, orders, products, and payments efficiently.

## Screens Designed
- Dashboard Overview
- Orders Management
- Products List
- Payments Tracking

## Features
- KPI cards
- Charts and data visualization
- Filters and tables
- Sidebar navigation

## Tools Used
- Figma
